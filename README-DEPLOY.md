# Super Mobile Shop – Netlify-এ চালু করার গাইড

## ফোল্ডার
```
netlify-site/
├─ netlify.toml                  নিরাপত্তা হেডার (CSP, HSTS...) + ফোল্ডার সেটিংস
├─ package.json                  @netlify/blobs (ডেটা সংরক্ষণ)
├─ .env.example                  কোন গোপন তথ্য লাগবে তার নমুনা (আসল মান কোডে/GitHub-এ নয়)
├─ netlify/functions/api.mjs     সার্ভার-সাইড API: লগইন, সেশন, ডেটা সংরক্ষণ, ছবি আপলোড
├─ public/index.html, app.js, style.css   ওয়েবসাইট
└─ src/input.css, tailwind.config.js      ডিজাইন-স্টাইল তৈরির উৎস
```

## চালু করার ধাপ (Git দিয়ে — এটাই লাগবে, শুধু ফোল্ডার টেনে ফেললে ফাংশন চলবে না)
1. `netlify-site`-এর ভিতরের সব ফাইল একটি নতুন **প্রাইভেট** GitHub রিপোজিটরির মূলে আপলোড করুন।
2. Netlify → **Add new site → Import an existing project** → রিপোজিটরি বাছুন। Build command ফাঁকা, Publish directory `public` (netlify.toml-এই দেওয়া আছে)।
3. **Site configuration → Environment variables**-এ দুটি মান বসান:
   - `ADMIN_PASSWORD` – কমপক্ষে ১০ অক্ষর; বড়-ছোট অক্ষর, সংখ্যা ও চিহ্ন মিশিয়ে লম্বা পাসওয়ার্ড।
   - `SESSION_SECRET` – কমপক্ষে ৩২ অক্ষরের র‍্যান্ডম লেখা। বানাতে: `openssl rand -base64 48`
4. **Deploys → Trigger deploy** করুন (মান বসানোর পর নতুন ডিপ্লয় লাগে)।
5. সাইট খুলে উপরে বাঁয়ে দোকানের নামে দ্রুত ৫ বার ট্যাপ (বা লিংকের শেষে `#admin`) → পাসওয়ার্ড দিন।
6. Settings → যোগাযোগ সেটিংসে আসল WhatsApp নম্বর, ফোন, ইমেইল দিন। Settings → ডেমো মোড বন্ধ করে আসল ফোন যোগ করুন।
7. ডোমেইন বদলালেও হোস্টিং একই থাকে: Netlify → Domain management → Add domain; HTTPS নিজে থেকে চালু হয়।

পাসওয়ার্ড বদলাতে: Netlify-তে `ADMIN_PASSWORD` বদলে আবার ডিপ্লয় করুন (বদলালে চালু সেশনও পুরোনো পাসওয়ার্ডে আর নতুন লগইন হবে না; `SESSION_SECRET` বদলালে সবার সেশন বাতিল হয়)।

## যে নিরাপত্তা বাস্তবে করা আছে
- **পাসওয়ার্ড সার্ভারে**, ব্রাউজারের কোডে নেই। তুলনা টাইমিং-নিরাপদ।
- **সেশন:** সই করা (HMAC-SHA256), `HttpOnly; Secure; SameSite=Strict` কুকি, ২ ঘণ্টা মেয়াদ; ১৫ মিনিট নিষ্ক্রিয় থাকলে ব্রাউজার লগআউট করে দেয়।
- **CSRF:** প্রতিটি লেখার অনুরোধে একই-অরিজিন যাচাই + আলাদা টোকেন।
- **ব্রুট-ফোর্স:** ভুল পাসওয়ার্ডে ধীর উত্তর; একই IP থেকে ৫ বার ভুলে সাময়িক লক (ক্রমে বাড়ে, সর্বোচ্চ ১ ঘণ্টা); সব IP মিলে অস্বাভাবিক ভুল হলে ১০ মিনিটের লক।
- **ডেটা সংরক্ষণ শুধু সার্ভার-যাচাইয়ের পর:** অনুমোদিত ফিল্ড ছাড়া সব বাদ, HTML চিহ্ন ছাঁটা, সংখ্যা/রঙ/URL যাচাই, আকার সীমা।
- **ছবি আপলোড:** শুধু অ্যাডমিন; jpg/png/webp; ফাইলের প্রথম বাইট (magic bytes) যাচাই; SVG বাতিল; ৫০০KB সীমা; র‍্যান্ডম নামে সংরক্ষণ; `nosniff` ও কড়া CSP সহ পরিবেশন।
- **হেডার (netlify.toml):** CSP (`script-src 'self'` – ইনলাইন স্ক্রিপ্ট নেই), HSTS, X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy, COOP/CORP।
- লুকানো ফোন সার্ভার থেকে সাধারণ গ্রাহকের কাছে পাঠানোই হয় না।

## সীমাবদ্ধতা (সৎ তালিকা)
- **একজন অ্যাডমিন, একটি পাসওয়ার্ড।** আলাদা ব্যবহারকারী, ভূমিকা, দুই-ধাপ যাচাই (2FA), "পাসওয়ার্ড ভুলে গেছি" নেই। বহু-ব্যবহারকারী বা 2FA লাগলে Auth0/Clerk/Supabase Auth-এর মতো সেবা জুড়তে হবে।
- দুজন একসাথে সেটিংস বদলালে শেষ সংরক্ষণই টিকবে (last-write-wins)।
- CSP-তে `style-src-attr 'unsafe-inline'` আছে (ডিজাইনের ইনলাইন `style=` এর জন্য); স্ক্রিপ্টে নেই।
- অব্যবহৃত পুরোনো ছবি মুছে ফেলার স্বয়ংক্রিয় ব্যবস্থা নেই।
- রেট লিমিট Netlify Blobs-ভিত্তিক সরল ব্যবস্থা; এটা WAF বা DDoS সুরক্ষা নয় (Netlify-এর নিজস্ব সুরক্ষা আলাদা)।
- অর্ডার ম্যানেজমেন্ট, পেমেন্ট গেটওয়ে, ওয়িশলিস্ট, ফোন তুলনা নেই; কার্ট থেকে WhatsApp/ইমেইল/ফোনে বুকিং যায়।
- ফোনের আসল ছবি দেওয়া নেই; নিজস্ব তৈরি রেন্ডার ব্যবহার হয়েছে। আসল ছবি অ্যাডমিন থেকে আপলোড করুন।

## আমি যা পরীক্ষা করেছি, আর যা করিনি
- **করেছি:** API-র ৩০টি নিরাপত্তা পরীক্ষা (ভুল/সঠিক লগইন, লক, কুকি ফ্ল্যাগ, CSRF, ভুয়া অরিজিন, নষ্ট কুকি, স্যানিটাইজেশন, লুকানো ফোন, ছবি আপলোড/ভুয়া ছবি/SVG বাতিল, লগআউট)। এবং ব্রাউজারে ২২টি এন্ড-টু-এন্ড পরীক্ষা, কড়া CSP হেডারসহ (লগইন, সংরক্ষণ, ছবি আপলোড, অন্য ব্রাউজারে গ্রাহক পরিবর্তন দেখছে কিনা, সার্চ/বাজেটে ফলাফলে স্ক্রল ও বার্তা)।
- **সীমা:** এই পরীক্ষাগুলো Netlify Blobs-এর **নকল (ইন-মেমরি) সংস্করণে** চলেছে; আসল Netlify-তে আমি ডিপ্লয় করতে পারিনি। ডিপ্লয়ের পর নিচের তালিকা নিজে মিলিয়ে নিন।

## ডিপ্লয়ের পরের চেকলিস্ট
1. লগইন হচ্ছে? ভুল পাসওয়ার্ডে ত্রুটি আসছে?
2. Settings-এ নাম বদলে সংরক্ষণ → অন্য ফোন/ব্রাউজারে সাইট খুলে নতুন নাম দেখা যাচ্ছে?
3. ফোন যোগ + ছবি আপলোড → অন্য ব্রাউজারে ছবিসহ দেখা যাচ্ছে?
4. https://securityheaders.com ও ব্রাউজারের কনসোলে কোনো CSP ত্রুটি নেই?
5. Lighthouse (Chrome DevTools) চালান; ফলাফল দেখে প্রয়োজনে জানান।
6. কোড `consistency: "strong"` ব্যবহার করে; ইনস্টল হওয়া `@netlify/blobs` সংস্করণে সমস্যা করলে `netlify/functions/api.mjs`-এ ওই অপশন সরিয়ে দিন।
